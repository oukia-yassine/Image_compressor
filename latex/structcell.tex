\doxysubsection{Description détaillée}
Représente un élément (noeud) d\textquotesingle{}une liste chaînée pour une couleur donnée. 


\begin{DoxyItemize}
\item Cette structure est utilisée pour gérer les collisions dans l\textquotesingle{}histogramme ou pour stocker les composantes de couleur (Bleu) associées à un couple (Rouge, Vert). 
\end{DoxyItemize}
